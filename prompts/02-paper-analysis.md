# Prompt 2：分析论文并设计改进

先填写真实论文和代码地址。模型无法读取的材料应由你提供，不应要求它假装已阅读。

```text
我计划复现并改进这篇深度学习论文：

论文：[公开链接或提供的全文]
代码仓库：[公开链接或本地项目路径]
硬件与实验预算：[填写]

请先阅读可访问的论文和代码，列出实际读到的材料与无法核实的部分，再分析：
1. 原论文解决什么问题，输入输出是什么？
2. 核心方法、模型结构和执行流程是什么？对应哪些代码入口？
3. 论文真正的创新点是什么，证据是什么？
4. 原方法有哪些局限？哪些是论文已承认的，哪些只是待验证假设？
5. 哪些模块可以低成本改进？

请提出 3～5 个具体、可检验的改进方案。每个方案给出：
- 假设与预期机制
- 需要修改的模块和最小实现步骤
- 显存、运行时间和代码修改难度估计
- 与原方法的公平对照方式，以及必要的消融实验
- 失败时如何判断原因
- 相关工作和重复风险；无法检索时明确说明

优先考虑小幅、有效且可验证的方法创新；尽量复用现有代码和预训练权重。不要单纯堆叠模块或盲目替换更大模型。

最后推荐最值得优先尝试的方案，说明选择理由和完整技术流程。只有在代码与依赖已充分核实时，才进一步生成可运行的改进代码；否则先列出缺失信息与验证步骤。
```
